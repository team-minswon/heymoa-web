## 웹과 앱은 이렇게 달라요 {#overview}

데스크톱 앱은 내 마이크와 컴퓨터에서 나는 소리를 함께 기록해요. 화상회의 상대방의 목소리도 컴퓨터 소리에 들어가요. 창을 닫아도 녹음은 이어져요. 화면은 웹 서비스와 같아요.

| | 웹(브라우저) | 데스크톱 앱 |
|---|---|---|
| 내 마이크 소리 기록 | ✓ | ✓ |
| 컴퓨터에서 나는 소리 기록 | ✗ | ✓ |
| 창을 닫아도 녹음 계속 | ✗ | ✓ |
| 설치 | – | 필요해요 |

Mac은 macOS 14.2 이상(Apple Silicon)에서 설치할 수 있어요. 설치 파일은 [다운로드 페이지](/download)에 있어요.

## 설치하는 법 {#install}

Mac은 macOS 14.2 이상(Apple Silicon), Windows는 Windows 11 x64에서 써요. 그 밖의 환경에서는 “지원하지 않는 환경”이라고 나오고 앱이 꺼져요. 컴퓨터 소리를 녹음하는 방식이 운영체제(OS)마다 달라서, 작동을 확인한 환경에서만 실행돼요. 이럴 땐 브라우저에서 웹 서비스를 쓰세요. 마이크 소리만 기록돼요.

::::tabs
:::tab{title="Mac"}
1. **[공식 배포 페이지](https://github.com/team-minswon/homebrew-tap/releases)에서 파일을 받아요**
   Apple Silicon Mac은 이름이 `mac-arm64.dmg` 로 끝나는 파일이에요.
2. **HeyMoa를 응용 프로그램 폴더로 옮겨요**
   받은 DMG를 열고 끌어다 놓으세요.
3. **처음 실행해요**
   인터넷에서 받은 앱이라는 확인 창이 뜨면 **[열기]** 를 눌러요. Mac 앱은 Apple 서명·공증을 받았어요.

Homebrew(맥용 설치 도구)를 쓴다면 터미널에 아래 명령을 입력해도 설치돼요.

```
brew install --cask team-minswon/tap/heymoa
```
:::
:::tab{title="Windows"}
1. **[공식 배포 페이지](https://github.com/team-minswon/homebrew-tap/releases)에서 파일을 받아요**
   이름이 `win-x64.exe` 로 끝나는 파일이에요.
2. **받은 파일을 실행해요**
   설치가 시작돼요.

> [!참고]
> Windows 설치 파일에는 서명이 없어서 SmartScreen 경고가 뜰 수 있어요.
:::
::::

> [!팁]
> 받은 파일이 공식 파일과 같은지 보려면, 파일의 SHA256 값을 공식 배포 페이지의 `SHA256SUMS` 와 비교하세요. SHA256은 파일마다 다른 확인용 문자열이에요.

## 처음 실행하고 로그인하는 법 {#first-run}

앱을 처음 실행하면 “HeyMoa 시작하기” 창이 떠요. 마이크와 컴퓨터 소리 설정을 안내하는 창이고, 여기서는 녹음하지 않아요.

1. **마이크 사용을 허용해요**
   **[내 목소리]** 칸에서 해요. Mac은 **[마이크 허용]** 을 눌러요. 권한을 거부했거나 Windows라면 **[설정 열기]** 로 OS의 마이크 설정을 열어요. 상태는 “허용됨”, “허용이 필요해요”, “기기에서 제한됨” 중 하나로 보여요.
2. **컴퓨터 소리 권한은 첫 녹음 때 허용해요**
   Mac에서 권한을 요청하면 허용하세요. 시스템 설정의 개인정보 보호 및 보안에서도 볼 수 있어요. macOS와 앱 버전에 따라 “시스템 오디오 녹음”이나 “화면 및 시스템 오디오 녹음”으로 나와요. Windows는 지금 소리가 나오는 스피커나 헤드셋의 소리를 녹음해요.
3. **권한 상태를 다시 확인해요**
   설정을 바꾸고 앱으로 돌아오면 상태가 바뀌어요. 직접 확인하려면 **[다시 확인 ↻]** 을 누르세요.
4. **시작해요**
   마이크를 허용했으면 **[HeyMoa 시작하기]** 를, 아직이면 **[나중에 설정하고 시작하기]** 를 눌러요. 한 번 마치면 이 창은 다시 뜨지 않아요.
5. **앱에서도 로그인해요**
   앱과 브라우저의 로그인은 따로예요. 로그인 버튼을 누르면 기본 브라우저에 로그인 화면이 열려요. 로그인을 마치면 앱으로 돌아와요. 브라우저가 HeyMoa를 열지 물으면 허용하세요.

5분 안에 로그인하지 않으면 “로그인 시간이 지났습니다”가 떠요. 로그인 버튼을 다시 누르세요.

## 앱으로 회의 녹음하기 {#recording}

앱에서 녹음하면 내 마이크와 컴퓨터에서 나는 소리가 함께 기록돼요. 화상회의 상대방의 목소리도 컴퓨터 소리에 들어가요. 녹음 버튼과 **[중지]**, **[재개]**, **[회의 종료]** 는 웹과 같아요.

다만 Zoom, Webex 같은 앱마다 상대방 소리가 잘 녹음되는지는 아직 확인하고 있어요.

녹음 중 “마이크가 끊겼습니다”나 “컴퓨터 소리가 끊겼습니다”가 뜨면, 끊긴 동안의 소리는 기록되지 않아요. 장치 연결과 음소거를 확인하세요.

> [!참고]
> ==창의 닫기 버튼을 눌러도 앱은 꺼지지 않고 창만 숨겨져요.== 녹음은 계속돼요. 다시 열려면 메뉴 막대(Mac)나 작업 표시줄 알림 영역(Windows)의 HeyMoa 아이콘을 누르세요.

## 메뉴 막대와 트레이 쓰는 법 {#menubar}

::clip{name="desktop-menubar" alt="메뉴 막대 아이콘을 눌러 팝오버가 열리고, 녹음 중 결정·할 일·열린 질문이 쌓이며, 녹음 중지로 대기 상태가 되는 영상" caption="화면은 예시예요. 메뉴 막대 아이콘을 누르면 지금 회의의 타임라인이 열려요."}

메뉴 막대(Mac)와 작업 표시줄 알림 영역(Windows)의 아이콘으로 녹음 상태를 볼 수 있어요.

아이콘을 누르면 지금 회의의 타임라인이 열려요. **[전체]**, **[결정]**, **[할 일]**, **[열린 질문]**, **[참고]** 중에서 볼 내용을 골라요. **[현재 회의 열기 ↗]** 로 회의 화면을 열고, **[■ 녹음 중지]** 로 녹음을 멈춰요.

30초 넘게 새 내용이 없으면 “갱신이 멈췄습니다”가 떠요. 회의를 열어 확인하세요.

녹음 중이 아닐 때는 “녹음 대기”로 열리고 “녹음 중인 회의가 없습니다.”가 보여요. 다른 사람이 기록 중인 회의를 보는 동안에는 녹음 중지 자리가 **[보기 종료]** 로 바뀌어요. Mac에서는 녹음 중에 아이콘 옆으로 녹음 시작 후 지난 시간이 보여요.

아이콘을 오른쪽 클릭하면 메뉴 첫 줄에 지금 상태가 나와요. 예를 들어 “녹음 중 · 시작 후 12:34”처럼 보여요. 상태 이름은 이런 뜻이에요.

- **전송 대기**: 아직 서버로 보내지 못한 소리가 컴퓨터에 남아 있어요.
- **마이크 음소거 / 시스템 소리 일시 중단 / 시스템 소리 종료**: 해당 마이크나 컴퓨터에서 나오는 소리는 지금 기록되지 않아요.
- **앱 종료 대기**: 녹음을 마무리하고 앱을 끄려고 기다리는 중이에요.
- **녹음 상태 확인 불가**: 회의 화면을 열어 녹음 상태를 확인하세요.

## 녹음 멈추기와 앱 끄기 {#quit}

**[녹음 중지]** 는 녹음만 멈춰요. 회의는 끝나지 않아서 이어서 기록할 수 있어요. 회의를 마치려면 회의 화면에서 **[회의 종료]** 를 누르세요.

메뉴에서 **[앱 종료]** 를 고르거나 Mac에서 `kbd:⌘Q` 를 누르면, 녹음 중이거나 보내지 못한 소리가 있을 때 확인 창이 열려요. 바로 꺼지지 않아요.

1. **[녹음 종료 후 앱 종료]를 골라요**
   녹음을 멈추고 소리를 모두 보낸 뒤에 앱이 꺼져요. 30초가 지나도 끝나지 않으면 안내가 떠요.
2. **기다리다 취소하고 싶으면 [앱 종료]를 다시 눌러요**
   그다음 **[앱 종료 취소]** 를 골라요.

> [!되돌릴 수 없어요]
> **[소리를 버리고 종료…]** 를 고르면 한 번 더 확인한 뒤 앱이 바로 꺼져요. ==서버에 저장되지 않은 소리는 되살릴 수 없어요.==

## 새 버전으로 바꾸는 법 {#update}

자동 업데이트는 없어요. 새 버전이 나왔는지는 [공식 배포 페이지](https://github.com/team-minswon/homebrew-tap/releases)에서 확인하세요. 화면과 기능은 대부분 웹과 함께 바로 바뀌어요. 다만 소리 녹음이나 메뉴 막대 같은 앱 자체 기능은 새 버전을 설치해야 바뀌어요.

1. **녹음을 멈춰요**
   녹음 중에는 업데이트하지 않아요.
2. **앱을 꺼요**
   앱이 완전히 꺼져야 새 버전을 설치할 수 있어요.
3. **새 버전을 설치해요**
   Mac은 새 DMG의 HeyMoa를 응용 프로그램 폴더에 덮어써요. Homebrew는 `brew upgrade --cask heymoa` 를 실행하세요. Windows는 새 설치 파일을 실행해요.

로그인할 때 “앱을 업데이트한 뒤 다시 로그인해 주세요”가 뜨면 앱을 업데이트해야 해요. **[새 버전 보기]** 를 눌러 새 버전을 받으세요.

## 앱에서 문제가 생겼어요 {#trouble}

:::problem
**증상:** “녹음을 시작하지 못했습니다”가 떠요
**원인:** 마이크나 컴퓨터 소리 권한이 없는 경우가 많아요.
**해결 방법:** Mac은 개인정보 보호 및 보안의 마이크·오디오 녹음 권한을, Windows는 설정의 마이크 개인 정보 화면을 확인하세요. 첫 녹음에서 권한을 허용했다면 녹음 버튼을 한 번 더 눌러 보세요. 계속 안 되거나 macOS가 앱 종료를 요청하면 앱을 완전히 끄고 다시 여세요. Mac은 창을 닫아도 앱이 숨기만 하니, 메뉴의 **[앱 종료]** 나 `kbd:⌘Q` 로 끄세요. 녹음은 저절로 다시 시작되지 않아요.
:::

:::problem
**증상:** 상대방 소리가 녹음되지 않아요
**원인:** 그 소리가 이 컴퓨터에서 나오지 않고 있을 수 있어요.
**해결 방법:** 소리가 이 컴퓨터에서 들리는지 확인하세요. Windows는 소리 설정의 출력 장치도 확인하세요.
:::

:::problem
**증상:** “소리 캡처가 중단됐습니다”가 떠요
**원인:** 녹음이 멈췄어요. 앱 화면이 잠시 응답하지 않으면 이럴 수 있어요. 마지막 소리 일부가 빠졌을 수 있어요.
**해결 방법:** 회의 화면에서 녹음을 다시 시작하세요.
:::

:::problem
**증상:** “앱 화면이 중단되었습니다”가 떠요
**원인:** 앱 화면이 멈췄어요. 보내지 못한 소리는 사라질 수 있어요.
**해결 방법:** **[다시 열기]** 를 누르세요. 녹음은 저절로 다시 시작되지 않으니 회의에서 직접 시작하세요.
:::

:::problem
**증상:** “HeyMoa에 연결하지 못했습니다”가 떠요
**원인:** 인터넷 연결이 불안정해요.
**해결 방법:** 인터넷 연결을 확인하고 **[다시 시도]** 를 누르세요.
:::

:::problem
**증상:** 로그인이 안 돼요
**원인:** “로그인하지 못했습니다”가 뜨면 로그인 과정이 끊긴 거예요. 브라우저에서 로그인했는데 앱이 그대로라면 브라우저가 HeyMoa 열기를 묻고 있을 수 있어요.
**해결 방법:** 로그인 버튼을 다시 누르고, 브라우저에서 HeyMoa 열기를 허용하세요.
:::

> [!참고]
> Bluetooth 헤드셋으로 한 녹음과, 절전에서 깨어난 뒤의 녹음은 아직 확인 중이에요. 녹음 중에 끊김 안내가 뜨면 녹음을 멈췄다가 다시 시작하세요.

마이크를 못 찾거나 실시간 스크립트가 연결되지 않는 문제는 웹에서도 생겨요. [문제 해결](help:troubleshooting)에서 확인하세요.

## 자주 묻는 질문 {#faq}

### 창을 닫으면 녹음이 멈추나요?
아니요. 창을 닫아도 앱은 꺼지지 않고 녹음이 이어져요. 다시 열려면 메뉴 막대나 작업 표시줄 알림 영역의 HeyMoa 아이콘을 누르세요.

### 자동으로 업데이트되나요?
아니요. 자동 업데이트는 없어요. 새 버전이 나오면 직접 설치하세요.

### Intel Mac에서도 쓸 수 있나요?
아니요. Mac은 Apple Silicon만 지원해요. 대신 브라우저에서 웹 서비스를 쓸 수 있어요. 마이크 소리만 기록돼요.

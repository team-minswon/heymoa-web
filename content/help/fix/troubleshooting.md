## 녹음이 시작되지 않을 때 {#recording}

:::problem
**증상:** “마이크 권한이 필요합니다”가 떠요
**원인:** 브라우저에서 마이크 사용이 허용되지 않은 상태예요.
**해결 방법:** 브라우저 사이트 설정에서 마이크 사용을 허용하세요. 그런 다음 녹음 버튼을 다시 누르세요.
:::

:::problem
**증상:** “사용할 수 있는 마이크를 찾지 못했습니다”가 떠요
**원인:** 사용할 수 있는 마이크가 없는 상태예요.
**해결 방법:** 마이크가 연결돼 있는지 확인하세요.
:::

:::problem
**증상:** “녹음을 시작하지 못해 세션이 만료되었습니다. 다시 시도해 주세요.”가 떠요
**원인:** 시작한 뒤 1분 안에 연결되지 않았어요.
**해결 방법:** 녹음 버튼을 다시 누르세요.
:::

:::problem
**증상:** **[회의 종료]** 버튼이 눌리지 않아요
**원인:** 기록 중에는 이 버튼을 누를 수 없어요.
**해결 방법:** **[일시정지]** 를 누른 뒤 **[회의 종료]** 를 누르세요.
:::

## 연결이 안 될 때 {#connection}

:::problem
**증상:** “실시간 스크립트 서버에 연결하지 못했습니다”가 떠요
**원인:** 로그인 상태나 인터넷 연결에 문제가 있을 수 있어요.
**해결 방법:** 로그인 상태와 인터넷 연결을 확인하세요. 그런 다음 녹음 버튼을 다시 누르세요.
:::

:::problem
**증상:** “다른 탭이나 기기에서 이 회의를 녹음하고 있어요”가 떠요
**원인:** 같은 회의를 다른 탭이나 기기에서 이미 기록하고 있어요.
**해결 방법:** 그 탭이나 기기에서 기록을 일시정지하세요.
:::

:::problem
**증상:** “녹음하던 기기와 연결이 끊겼어요”가 떠요
**원인:** 녹음하던 기기와 연결이 끊긴 상태예요.
**해결 방법:** ==그 기기의 녹음이 정리되는 약 1분 뒤에 다시 시도하세요.==
:::

:::problem
**증상:** “연결이 끊겨 녹음을 멈췄어요”가 떠요
**원인:** 네트워크 연결이 끊겨 녹음이 멈췄어요.
**해결 방법:** 네트워크를 확인한 뒤 **[재개]** 를 눌러 이어서 기록하세요.
:::

:::problem
**증상:** “음성 인식 서비스 연결이 중단되었습니다. 잠시 후 다시 시도해 주세요.”가 떠요
**원인:** 음성 인식 서비스와 연결이 끊겼어요.
**해결 방법:** 잠시 뒤 **[재개]** 를 눌러 이어서 기록하세요.
:::

## 요약이 안 보일 때 {#summary}

:::problem
**증상:** “분석을 기다리고 있습니다”가 떠요
**원인:** 아직 분석을 요청하지 않은 상태예요.
**해결 방법:** **[분석 요청]** 을 누르세요.
:::

:::problem
**증상:** “회의를 분석하지 못했습니다”가 떠요
**원인:** 분석이 실패했어요.
**해결 방법:** **[다시 분석]** 을 누르세요. 스크립트와 회의 기록은 그대로 남아 있어요.
:::

:::problem
**증상:** “화자를 나누지 못했습니다”가 떠요
**원인:** 화자 나누기가 실패했어요.
**해결 방법:** 요약은 화자 없이 만들어져요. 이름은 스크립트에서 직접 붙이세요.
:::

## 초대·삭제·권한 안내가 뜰 때 {#workspace}

:::problem
**증상:** “초대가 만료되었습니다”가 떠요
**원인:** 초대 링크가 유효한 기간이 지났어요.
**해결 방법:** ==초대 링크는 1일 동안만 유효해요.== 관리자에게 다시 초대해 달라고 요청하세요.
:::

:::problem
**증상:** “이 초대는 다른 이메일 계정용입니다”가 떠요
**원인:** 초대받은 이메일과 다른 계정으로 로그인했어요.
**해결 방법:** 초대받은 이메일의 Google 계정으로 로그인하세요.
:::

:::problem
**증상:** “지금은 초대를 보낼 수 없습니다. 잠시 후 다시 시도해 주세요.”가 떠요
**원인:** 하루에 보낼 수 있는 초대 수를 넘었어요.
**해결 방법:** 시간이 지난 뒤 다시 보내세요.
:::

:::problem
**증상:** “노트가 있는 프로젝트는 삭제할 수 없습니다.”가 떠요
**원인:** 노트가 하나라도 있으면 프로젝트를 삭제할 수 없어요.
**해결 방법:** 관리자가 그 프로젝트의 노트를 모두 지운 뒤 프로젝트를 삭제하세요.
:::

:::problem
**증상:** “워크스페이스를 변경할 권한이 없습니다.”가 떠요
**원인:** 관리자가 아닌 계정으로 관리자 전용 설정을 바꾸려 했어요.
**해결 방법:** 워크스페이스 이름 변경, 연동, 멤버 관리는 관리자만 할 수 있어요. 관리자에게 요청하세요.
:::

## 해결되지 않을 때 {#more}

데스크톱 앱에서 생기는 문제는 [데스크톱 앱](help:desktop#trouble)의 문제 해결에 있어요. 숫자 한도는 [한도와 규칙](help:limits)에서 확인하세요.

그래도 해결되지 않으면 사이드바 **[문의·피드백]** 에서 **[장애·오류]** 로 보내세요. 보내는 방법은 [문의·피드백](help:feedback)에 있어요.

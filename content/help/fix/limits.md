## 입력 길이와 개수 {#length}

| 무엇 | 한도 |
|---|---|
| 회의 이름 | 200자 |
| 회의 주제 | 200자 |
| 회의 배경 | 1000자 |
| 회의 참석자 | 계정과 임시 참여자 각각 200명 |
| 프로젝트 이름 | 100자 |
| 임시 참여자 이름 | 100자 |
| 이 워크스페이스에서 보일 멤버 이름 | 30자 |
| 용어 하나 | 40자 |
| 용어 사전 | 워크스페이스에 200개 |
| 용어 붙여 넣기 | 한 번에 100개 |
| 에이전트에게 질문할 때 범위로 붙이는 프로젝트와 회의록 | 합쳐서 20개 |
| 문의 | 1200자 |
| 회의록 메일의 메시지 | 1000자 |

## 횟수 제한 {#rates}

| 무엇 | 한도 |
|---|---|
| 초대 | 하루에 한 사람이 30건, 같은 주소에 3건 |
| 한 주소가 받는 초대 | 하루에 모두 합쳐 10건 |
| 문의 | 한 사람이 한 시간에 5건 |
| 회의록 메일 | 한 시간에 30회, 한 번에 10명 |
| 회의록 메일에 붙이는 PDF | 10MB 이하 |
| 내 에이전트로 보내는 회의 결과 메일 | 하루에 30건 |

## 기간과 시간 {#time}

| 무엇 | 기간 |
|---|---|
| 로그인 | 쓰지 않은 지 30일이 지나면 만료 |
| 초대 링크 | 보낸 뒤 1일 |
| 외부 AI 앱 연결 | 쓰지 않은 지 90일이 지나면 만료 |
| 메일로 보낸 회의록 PDF | 30일 보관 |
| 회의 음성 | 화자 구분이 끝나면 삭제, 늦어도 30일 |
| 삭제한 데이터의 백업 | 최대 7일 |
| 중지한 회의 | 1영업일 뒤 메일, 3영업일 뒤 자동 종료 |

- 회의 분석: 12분 안에 끝나지 않으면 실패로 보여요. **[다시 분석]** 으로 다시 요청하세요.
- 녹음하던 기기와 연결이 끊김: 약 1분 뒤 다른 곳에서 이어서 기록할 수 있어요.

## 알아 둘 규칙 {#rules}

역할은 관리자와 멤버 둘뿐이에요.

- 관리자만 할 수 있는 일: 워크스페이스 설정, 연동, MCP 연결 관리, 멤버 초대·내보내기, 임시 참여자 이름 변경·연동·삭제, 노트·프로젝트·워크스페이스 삭제
- 멤버라면 누구나 할 수 있는 일: 노트 보기, 기록, 종료, 검토 확정, 할 일 고치기

> [!되돌릴 수 없어요]
> 종료한 회의는 다시 기록할 수 없고, ==확정한 검토는 되돌릴 수 없어요.== 회의를 분석하는 동안에는 노트를 삭제할 수 없어요.

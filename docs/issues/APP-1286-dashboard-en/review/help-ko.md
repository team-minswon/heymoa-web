# 사용 가이드 한국어 본문 평가

대상은 `content/help/<그룹>/*.md` 31편(영어판 `content/help/en/**`와 `README.md`는 제외)과 `messages/ko/help.json`이에요.
평가는 codex(`codex exec -s read-only`)로 두 번 받았어요. 5점이 가장 좋아요.

## 점수

| 축 | 1차 | 2차 |
|---|---|---|
| AI 티 | 4 | 3 |
| 번역투·피동·가운뎃점 나열 | 4 | 4 |
| 어조(해요체) | 5 | 5 |
| 화면 이름 정확성 | 3 | 4 |
| 평균 | 4.0 | 4.0 |

2차의 AI 티 3점은 새로 생긴 문제가 아니에요. 1차 지적을 고친 뒤 본문과 자주 묻는 질문이 겹치는 곳을 새로 짚은 결과이고, 그 지적도 반영했어요(아래).

## 반영한 지적

- 1차: 연동 실패 문구, 메일 다시 보내기·참석자 추가·참고한 회의록 버튼의 개수 표기, `나가져요` 같은 어색한 피동, 단계 제목을 설명에서 되풀이한 곳(초대 이메일, 회의 노트 열기), 한 단계에 형광펜이 연달아 붙은 곳, 같은 페이지 FAQ의 반복, 문제 해결 제목의 가운뎃점 나열
- 2차: 메일 결과 **[보내기 실패]**, 실시간 타임라인과 용어 사전 FAQ의 본문 반복, 할 일 추가 단계의 형광펜, 문의 읽음 표시 문장, `받아들여지지 않은` 피동

## 남긴 지적과 이유

- `first-meeting.md:4`, `export.md:4`(description의 가운뎃점), `use-mcp.md:4`(description의 「읽기만 할 수 있고」): front matter라서 이번 작업에서 건드리지 않았어요. `use-mcp` 설명은 이제 사실과 달라요. **[할 일 변경 허용]** 이 생겼기 때문이에요. 다음 작업에서 영어판 description과 함께 고쳐야 해요.
- 제목(`title`)의 가운뎃점(`회의록 PDF 저장·복사·메일 공유`, `문의·피드백`): 메뉴 이름과 페이지 제목이라 예외로 두었어요.
- 데스크톱 앱 창의 문구(**[앱 종료]**, **[마이크 허용]**, **[보기 종료]** 등)는 `messages/ko`에 없어요. `apps/desktop/**`의 원문과 대조해서 맞는 것을 확인했어요.
- 서버가 보내는 오류 문구(“녹음을 시작하지 못해 세션이 만료되었습니다…”, “지금은 초대를 보낼 수 없습니다…” 등)는 web 언어 파일에 없어서 대조하지 못했어요. 그대로 두었어요.

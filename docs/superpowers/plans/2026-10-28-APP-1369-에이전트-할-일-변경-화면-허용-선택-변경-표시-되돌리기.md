## 순서

### 1. 계약 사본과 목
- `node scripts/sync-openapi.mjs` → `pnpm orval`. 목의 연결·할 일·판에 새 필드를 채우고, 연결 만들기·동의 허락이 `allowTaskChanges` 를 받게 한다(동의는 요청 범위에 `mcp:write` 가 없는데 참이면 400)
- 검증: `pnpm typecheck`·`pnpm test:run` 통과(기존 시험 그대로)

### 2. 허용 선택과 연결 목록
- 새 연결·동의 화면 스위치와 안내, 연결 행 둘의 「할 일 변경 허용」 배지, 사용 내역 도구 이름 표
- 검증: 새 연결이 켰을 때만 `allowTaskChanges: true` 를 보낸다, 동의 화면은 `mcp:write` 를 요청했을 때만 스위치가 보인다, 배지는 허용한 연결에만

### 3. 변경 표시와 되돌리기
- 할 일 행의 「에이전트 · 연결 이름」, 이력의 「…의 에이전트(연결 이름)가 바꿨습니다」·「…가 HeyMoa 에이전트로」, 맨 위 외부 에이전트 판의 되돌리기
- 검증: 표시가 해당 판·할 일에만, 되돌리기가 직전 판 네 값과 지금 판 번호를 보낸다, 판 1·맨 위가 아닌 판·멤버 판에는 없다

- 사용자가 안건·근거를 펼칠 때 자동 추종을 중지하고, 맨 아래로 이동하면 다시 추종합니다.

## UI 배치 수정

사용자 확인에 따라 별도 ‘충돌·이어짐’ 섹션은 제거합니다. 충돌은 기존 결정·할 일의 승인 검토 카드에 종류와 근거를 함께 표시합니다. 같은 출발 항목·대상 참조·판을 다루는 승인 제안에는 관계 근거를 합쳐 대상이나 선택을 중복으로 만들지 않습니다. 명제 판과 확정 항목 판은 각각의 참조로 대조합니다. 승인 제안이 없는 관계는 해당 항목 아래에서 읽고, 안건 이어짐은 주제 목차에 유지합니다. 선택은 검토본에 저장하고 실제 할 일 변경은 아래 일괄 적용 결정에 맞춥니다.

배치 수정 후 재검증: Vitest 204개 파일/2,558개 테스트, typecheck와 lint(기존 Virtualizer 경고 1개)를 통과했습니다. 검토 화면 E2E 5개는 중복 카드가 없는지, 기존 선택·편집·최종 확정과 좁은 화면을 확인했습니다. 공개 Mock 도메인의 실제 브라우저에서 별도 섹션 0개·기존 승인 카드 1개와 모바일 가로 넘침 0px, pageerror 없음을 확인했습니다.

## 회의 안 안건 그래프

기존 그래프 보기의 주제 허브 사이에 같은 회의 안건의 바로 앞 연결을 화살표로 표시합니다. 방향은 앞 안건에서 뒤 안건으로 읽으며 다른 회의 안건·없는 안건·자기 연결은 그리지 않습니다. 중복 쌍은 하나로 모읍니다. 포함 항목이 없어도 연결된 안건 허브는 남기고, 연결 수가 항목 수를 부풀리지 않도록 별도로 셉니다. 캔버스 아래에는 연결된 안건 이름을 같은 방향으로 표시합니다. 관계 조회 대기·실패 안내는 요약과 그래프 보기에서 모두 유지합니다.

검증: 그래프 모델·컴포넌트 25개 테스트와 요약·안건·자동 추종 E2E 8개를 통과했습니다. 공개 Mock 도메인에서 같은 회의의 안건 화살표와 이름을 확인했습니다.

## 기존 할 일의 일괄 적용

사용자는 검토 완료 때 일괄 적용하고 그전에는 반영과 넘기기를 자유롭게 바꾸는 방식을 선택했습니다. 서버 APP-1184가 선행하며 Web은 즉시 업무 PUT과 부분 반영 복구를 제거합니다. 원본 제안과 저장 초안을 구분하고 초안의 담당 참조는 화면에서 선택 목록과 연결해 이름을 표시합니다. 선택·담당·기한은 검토본에 저장하고 재진입에서도 복원합니다. 기대 업무 판은 원본 제안을 유지합니다.

새 APPLY 선택은 ‘반영 예정’으로 표시하고 기존 APPLIED는 읽기 전용 이력으로 유지합니다. 완료 막대와 확인창은 새로 적용할 기존 할 일만 셉니다. 승인 중 편집·중복 확정을 잠그고, 성공 뒤 전체·프로젝트별 목록 및 업무 이력을 갱신합니다. Mock도 초안 PATCH에서는 업무를 바꾸지 않고 승인 전에 전체 판·중복 검사를 마친 뒤 변경합니다.

## 재언급 안건과 안내 문구

같은 안건이 다른 안건 뒤에 나오면 현재 시각에 별도 묶음을 표시합니다. ‘이어서’와 ‘앞선 논의’ 링크만 추가하고 별도 연결 화면은 만들지 않습니다. 이전 논의로 이동할 때는 해당 묶음만 펼치고 긴 묶음도 제목부터 읽습니다. 모바일에서는 링크를 다음 줄에 둡니다. 새 명제는 안건 분류 전에도 바로 보이며, 분류 결과가 접힌 묶음에 붙으면 첫 화면부터 펼칩니다. 유형 필터로 가린 동안에도 새 내용이 붙었는지 기억하고 자동 추종을 다시 켜지 않습니다.

그래프의 반복적인 조작 설명을 삭제하고 관계·담당 상태 안내를 짧게 다듬었습니다. 실제 범례와 연결된 안건 이름은 유지합니다. 공개 Mock에서 데스크톱·모바일의 넘침 0px, 브라우저 오류 없음을 확인했습니다.

## 최종 피어리뷰 후 보완

승인 409에서 검토본뿐 아니라 업무 목록도 새로 읽습니다. 업무 판이 바뀌면 반영·편집을 막고 넘기기를 안내하며, 같은 업무의 복수 APPLY는 완료 전에 막습니다. 실제 Mock 업무 PUT→승인 409→업무 재조회→넘기기→승인 성공을 통합 테스트로 확인했습니다. 선택을 고친 뒤에는 이전 오류 문구를 지우고 현재 막힌 이유를 우선 표시합니다. 초안의 기한·담당 참조는 저장 응답 전에 표시하며 실패 시 선택과 함께 되돌립니다.

관계의 백그라운드 재조회 안내 깜박임, 최신 flow 조회 실패를 대기로 표시하는 문제와 그래프 zoom의 렌더 중 상태 갱신 경고도 수정했습니다. nullable 표본 검사는 선택 필드의 생략만 null로 세고 필수 필드의 생략은 null 표본으로 세지 않습니다.

Mock의 새 APPLIED 허용은 실제 서버의 호환 처리와 같으므로 유지합니다. 새 AI 안건은 description 빈 배열을 사용하고 옛 결과는 설명 전문을 보존합니다. 안건 연결은 source=current, target=previous 계약이므로 그래프가 target에서 source로 향합니다. 알 수 없는 관계 종류는 유추하지 않습니다. NOT_REQUESTED의 안건 폴링은 자동 분석 진입·늦은 결과를 받기 위한 대기 상태 갱신으로 유지합니다. 미분류 새 명제 뒤에는 이전 안건이 계속 논의 중이라고 추정하지 않습니다.

전체 브라우저 테스트 114개를 한 번에 통과했습니다. 이후 보완에는 전체 단위 검사와 관련 브라우저 테스트 9개를 다시 통과했습니다. 중단한 Playwright 실행이 남긴 임시 trace가 ESLint에 잡힌 실행은 통과로 세지 않고, 완료 뒤 임시 산출물을 정리한 상태에서 verify를 다시 통과했습니다.

Codex 1차 검토에서 승인 중 확인창 언마운트, 확정 후 APPLY를 미확정·충돌로 표시하는 문제, 요약에 없는 이슈·질문 관계 대상 이동 실패를 재현했습니다. 완료 막대의 표시 조건을 편집 잠금과 분리하고, 승인 실패에도 확인창을 유지합니다. 확정된 포함 항목의 APPLY는 ‘반영됨’, 제외 항목은 ‘제외됨’으로 구분합니다. 관계 대상을 고르면 필요한 경우 기존 그래프로 전환해 해당 상세를 열고 이동합니다. 느린 승인→실패→재시도→확정 표시, 제외 항목, 관계 대상 이동을 회귀 검사에 추가했습니다.

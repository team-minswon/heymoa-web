# APP-489 범위 지정 채팅 화면 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 개인 채팅 하나에 회의록·프로젝트를 여러 개 붙여 묻고, 턴이 브라우저 연결과 무관하게 살아 탭을 닫았다 돌아와도 그 자리부터 이어지는 화면을 만든다.

**Architecture:** 세 출처(히스토리 REST · SSE 프레임 · 목록 폴링)가 같은 대화를 서로 다른 시각으로 말하고, 그 셋을 **블록 한 배열**로 접는 것이 이 작업의 전부다. 순수 리듀서(`lib/chat/`)가 프레임 13종을 상태 여섯으로 접고, 훅(`use-chat-stream`)이 커서·재연결·탭 복귀를 쥐고, 컴포넌트는 그 결과만 그린다. MSW 목이 **서버와 같은 프레임을 같은 순서로** 내는 것이 검증의 바닥이다.

**Tech Stack:** Next.js 16 App Router · TanStack Query · MSW · Orval · Vitest · Playwright · Tailwind + shadcn/ui · react-markdown + remark-gfm

**Spec:** `../../../../docs/projects/PRO-40-범위-지정-채팅-구현/spec/APP-489/spec.md`

`TextDecoder({stream: true})` 로 읽고 `\n\n` 으로 프레임을 가른다. 줄머리 셋만 본다: `id:` → `Number`, `event:` → 문자열, `data:` → 누적. **`:` 로 시작하는 줄은 통째로 버린다** (하트비트).

async function settledScrollTop(viewport: Locator): Promise<number> {
  const read = () => viewport.evaluate((el) => el.scrollTop);
  let previous = -1;
  await expect
    .poll(async () => {
      const now = await read();
      const stable = now === previous;
      previous = now;
      return stable;
    }, { timeout: 5_000, intervals: [100] })
    .toBe(true);
  return read();
}
